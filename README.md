# Micrositio — Tienda Peralonzo

Proyecto académico de comunicación comercial construido con React, TypeScript y Vite.

## Requisitos
- Node.js LTS instalado
- Visual Studio Code (recomendado)

## Cómo abrirlo
1. Descomprime `tienda-peralonzo-micrositio.zip`.
2. Abre la carpeta `tienda-peralonzo-micrositio` en VS Code.
3. Abre la terminal integrada: **Terminal → New Terminal**.
4. Ejecuta:

   ```bash
   npm install
   npm run dev
   ```

5. Vite mostrará una dirección local, normalmente `http://localhost:5173/`. Ábrela en el navegador.

## Compilar para producción
```bash
npm run build
npm run preview
```

## Qué incluye
- Página responsive para celular y computador.
- Navegación por secciones.
- Modo exposición para reducir distracciones.
- Diagnóstico, público objetivo, mensaje, estrategia, cronograma y presupuesto.
- Tabla de presupuesto expandible.
- Botón para imprimir o guardar como PDF.

## Antes de presentar
- Completa los nombres de integrantes si tu instructor los exige.
- Confirma con el propietario los productos, servicios y canales reales.
- El presupuesto de $56.000 COP es una **estimación académica**, no una cotización real.
- WhatsApp se plantea solo si la tienda cuenta con ese canal.
- Las ilustraciones de la tienda son CSS y decorativas; no representan una fotografía real del local.
